📋 How to Use This Guide

  1. Fill in each text field with your real business information.
  2. Gather files for every item marked 📷 Image / File.
  3. Name each file using its reference code (the orange badge, e.g. G-005) — for example: G-005-logo-dark.png. This lets our team and AI tools place each file in exactly the right location automatically.
  4. Send everything in one folder/drive share.
  5. Items marked Required must be provided before work can begin. Optional items can be added later.
