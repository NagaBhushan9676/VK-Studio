# Client Assets — place originals here

Place original client asset files (logos, source files, fonts, legal docs) inside this folder. Do not rename files after upload; update `manifest.json` when adding new files.

Folder structure
- `logos/` — SVG + PNG logos (SVG preferred)
- `source/` — source files (PSD, AI, Sketch)
- `fonts/` — font files + license documents
- `docs/` — legal PDFs (Privacy Policy, Terms) and other documents

- Processed/optimized assets
- `static-site-ai-system/static-page-agent/outputs/generated-assets/` — web-optimized outputs (webp, resized images) created by agents.
- Final, approved images should be copied to `antra/assets/img/` and fonts to `antra/assets/fonts/` when ready for deployment.

Manifest
- Update `manifest.json` for every file you upload. Include filename, intended page, usage, and license info.
